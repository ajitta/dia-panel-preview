# dia-panel (preview, archived)

This preview has moved. `dia-panel` now ships in the `dia` marketplace:

```
claude plugin marketplace add ajitta/dialectic-skills
claude plugin install dia-panel@dialectic-skills
```

See [companions/dia-panel](https://github.com/ajitta/dialectic-skills/tree/main/companions/dia-panel). If you added this preview marketplace, remove it (`claude plugin marketplace remove dia-panel-preview`), so that dia-panel is not installed from two places.
